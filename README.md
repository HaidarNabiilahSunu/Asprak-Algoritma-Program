# Asprak Algoritma Program

Repository ini berisi kumpulan materi, latihan, dan program dari **Praktikum Algoritma dan Pemrograman 1** menggunakan bahasa pemrograman **Go (Golang)**.

Repository ini dibuat sebagai dokumentasi pembelajaran sekaligus tempat menyimpan hasil pengerjaan latihan praktikum selama perkuliahan **S1 Teknik Informatika – Telkom University**.

## 📚 Materi
 
Beberapa materi yang dipelajari dalam repository ini meliputi :

* Input dan Output
* Tipe Data
* Variabel
* Operasi Aritmatika
* Integer Division
* Modulo
* Casting / Type Conversion
* Percabangan
* Perulangan
* Penyelesaian soal algoritma dan pemrograman
